# AP-06 R12-R13: native MemoryInfra recovery

## Authority and scope

This is a new, independent native profiling campaign. Its antecedent scientific result is the immutable AP-06 R12-R12 decision, `R12R12_FACTORIAL_CONFIRMED`, from implementation HEAD `cbaf2ac1c831e9bc98b8e568435c69bd43304334`. It authorizes only A=`r12r2.0` (XHR/XHR) and B=`r12r2.2` (XHR/Fetch). The R12-R12 worktree, runtime, reservations, and credentials are not resumable state and must remain unchanged.

The campaign diagnoses the historical MemoryInfra trace offline, validates and repairs its capture/parser contract, then prepares an independent private authority and freeze. It does not rerun the factorial or select a different pair.

## Frozen capture contract

Use the existing `NativeTrace` for capability and A/B, one tracing session per browser, the four fixed checkpoints `baseline`, `cycle-6-close`, `idle-120s`, and `forced-GC-final`, and the existing Chromium flags, MemoryInfra category, streaming mode, 512 MiB trace cap, 32 MiB event cap, and timeouts. Do not change trace configuration by trial and error. A dump request success or category availability does not establish effective heap profiling. The consumer may confirm usable profiling only after four correlated renderer dumps contain valid `heaps_v2` allocator cohorts.

The parser accepts only the observed string GUID forms (`id` or `id2.global`) and rejects conflicts, malformed schema, PID mismatch, invalid ordering, truncation, data loss, non-finite numbers, and oversized input. Missing renderer metadata, dump coverage, or heap data is inconclusive. A metadata fallback requires a pre-registered proof joining the PID, process creation time, renderer role, retained Win32 handles, and the traced process across all checkpoints.

## Interpretation

Keep requested live allocation bytes, allocator statistics, renderer-private bytes, and reserved/committed memory separate. Report sampling and unknown allocator coverage. Aggregate snapshots do not identify individual allocation lifetimes; residual private bytes alone cannot establish a native leak. With at most one measurement per arm, any A/B result is exploratory and conditional on the previously confirmed factorial result.

The R12-R12 trace remains immutable. Public reports contain only sanitized counts, allowed categories, states, and hashes. Raw traces, stacks, paths, addresses, PIDs, and credentials stay in the private authority.
